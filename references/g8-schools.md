# 澳洲八大范围

只处理这八所。其他澳洲学校转到普通留学规划，或明确说本 Skill 只覆盖八大。

| 常用说法 | 英文 |
| --- | --- |

| 墨尔本大学 | The University of Melbourne |
| 悉尼大学 | The University of Sydney |
| 新南 / UNSW | UNSW Sydney |
| 莫纳什大学 | Monash University |
| 昆士兰大学 / UQ | The University of Queensland |
| 西澳大学 / UWA | The University of Western Australia |
| 阿德莱德大学 | The University of Adelaide |

层次：预科 / foundation、本科、授课型硕士、研究型硕士。预科和桥梁按目标本科或硕士项目核对，不把预科录取说成本科直录。

查条件、学费、截止日用院校 MCP 和官网。缺字段不编。CoE、GS、签证按学校和内政部分开说。
