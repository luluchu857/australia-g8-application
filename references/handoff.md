# 一键递交到平台

材料交到联合招生官平台，由联合招生官协助，不直接替学生点学校官网。

## 学生流程

1. Skill 整理清单；学生想递交时先问一句要不要交给联合招生官免费协助。
2. 学生确认后打开 `https://hi.xwoork.cn/student/upload`。网址只表示「打开全屏文件」，不含 pack、国家或学校。
3. 未填名称就先填名称、确认咨询，进入咨询室。
4. 一进入咨询室就弹出入口问卷（不用等文件上传）：姓名、手机、邮箱、国家/地区、层次、入学季、目标学校；选填专业和微信号。学生可先填，也可先关掉。
5. 学生进来后默认是全屏文件管理。Skill 把已经拿到的文件逐个传上去：服务端回执 `received` 只表示“平台已收到”。页面开着时，几秒内会出现“已收到 N 个文件，正在整理”，随后文件出现在 `intake` 文件夹；不是文件一边传一边显示进度。
6. 学生点保存提交问卷。成功文案：提交成功，请等联合招生官联系；右下角可继续在线咨询。

对学生的说法：拿到 PUT 回执后说“文件已发送到平台，几秒内会出现在页面的 intake 文件夹里”。几秒后仍没看到，就请学生刷新页面或重新进入咨询室再看；不要说“没传上”，也不要重传，可用 `get_intake_status` 核对每个文件的状态（`received` 已收到、`copied` 已整理、`failed` 整理失败）。

## 接口（网页要写，Skill 来调）

现有咨询页的文件上传只能由学生在浏览器里点选。浏览器关掉后，这类上传会停。Skill 自动上传必须走服务端接口，由 MCP/宿主进程把文件交给平台，不能假扮成页面按钮。

申请助手工具：

- `open_advisor(landing=upload|consult)`：返回对应学生页。疑惑走 consult；确认递交走 upload。
- `start_intake(student_code=…)`：创建一次性交接票（student_code 是全球版 `student_code.py ensure` 返回的 8 位 ID，没有就不传），返回带 `ticket` 的 `/student/upload` 和 `upload_url`。票号可进查询参数，不要进姓名手机、也不要进 pack/国家。
- 已拿到的文件：宿主 HTTP PUT 到 `upload_url`，请求头 `x-filename`。不要把大文件塞进 JSON。`upload_intake_file` 只适合很小的文件。
- `get_intake_status`：身份是否确认、每个文件的状态（`received` / `copied` / `failed`，`copied` 带 `case_file_id`）、问卷是否已发。
- 问卷由平台在学生确认咨询并绑定交接票后自动发送，不必联合招生官再点发送。国家/学校以学生问卷为准。

页面路由：

- `/student`：默认聊天咨询。
- `/student/upload`：确认咨询、进入咨询室后默认全屏文件管理；入口问卷进入咨询室即弹出。

关掉页面：MCP 上传继续；浏览器里学生自己选的文件会中断。

当前 `submit_to_hri` 仍只返回入口，不收附件。未接到成功回执前，不能说已登记、已上传或已向学校递交。
