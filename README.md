# 澳洲八大申请

针对澳洲八大（ANU、墨尔本、悉尼、UNSW、莫纳什、昆士兰、西澳、阿德莱德）预科、本科和研究生的选校、案例、材料整理，以及联合招生官咨询 / 材料递交。其他国家或多国比较请用 study-abroad-planner。

找真人、明确有疑虑或听不懂、问怎么递交、方案最终确认时，打开咨询页；想把材料交给联合招生官时，先问一句再打开上传页。咨询页语音直接用网页麦克风。
